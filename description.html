Task Explanations

1. Reverse a string

Takes input text and returns it backwards using split(), reverse(), join().

2. Extract 3rd and 4th characters

Gets characters at positions 3 and 4 from string using charAt().

3. Find longest word

Splits sentence into words and finds word with maximum length.

4. Convert string to lowercase

Changes all characters to lowercase using toLowerCase().

5. Convert string to uppercase

Changes all characters to uppercase using toUpperCase().

6. Detect words + special symbols

Counts words and special characters using split() and regex.

7. Create array of numbers

Converts comma-separated string into number array.

8. Display third element

Shows element at index 2 from array.

9. Find last element from array

Gets last item using array[array.length-1].

10. Find 10th character

Uses prompt() for input and charAt(9) for 10th character.

11. Apply map to double

Uses map() method to multiply each element by 2.

12. Splice delete

Removes elements from array using splice().

13. Arithmetic operations

Performs add, subtract, multiply, divide based on selection.

14. Add two numbers

Simple addition function.

15. Multiply two numbers

Simple multiplication function.

16. Divide two numbers

Division with zero check.

17. Check even/odd

Uses modulus operator % to check if number is even.

18. Display form data

Shows entered form values in formatted output.

19. Form data count

Counts how many form fields are filled.

20. Create person object

Creates JavaScript object with properties.

JavaScript Methods Used

split(), reverse(), join(), charAt(), toLowerCase(), toUpperCase(), map(), splice(), parseFloat(), isNaN(), prompt(), JSON.stringify()
